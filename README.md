# CraftKit
AI-powered offline vehicle inspection tool in a single portable EXE. Features license plate OCR, YOLO damage detection, before/after image comparison &amp; auto PDF reports. Built with regex parsing, color-space converters (RGB/HSV/LAB) &amp; base64 embedding. No installation, no cloud — just run CraftKit.exe and inspect.
